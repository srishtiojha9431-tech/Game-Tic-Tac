# Game:-Tic-Tac

Tic Tac Toe Console Game using C++

📖 Project Description

This project is a console-based Tic Tac Toe Game developed in C++.
The game allows two players to play against each other in the terminal.

✔The project demonstrates the use of:

• Arrays

• Loops

• Conditional Statements

• Functions

• Game Logic Implementation

✨ Features:

•Interactive console gameplay

•Dynamic board display

•Two-player mode

•Input validation

•Win detection

•Draw detection

•Replay functionality

•User-friendly interface

✔The game dynamically updates the board after every move and checks for:

•Win conditions

•Draw conditions

•Replay option

Developed as a Mini Game Project using C++.
